# UI Design System

LiquidGlass es referencia tanto para la interfaz como para posibles motion effects. La app debe usar glass/refractive treatments con moderación y performance budgets.

## UI
- floating/dockable inspectors;
- translucent project cards/panels;
- clear contrast and keyboard focus;
- reduced-motion/performance mode;
- no sacrificar legibilidad por efecto.

## Video
`glass.panel`, `glass.refraction`, `glass.lower-third`, `glass.data-card` pueden ser Visual/Motion Packs renderizados por VideoFlow/Remotion/WebGL adapter.

La implementación visual de la app y la implementación de un efecto dentro de un video son plugins/capas distintas.
