# Roadmap de desarrollo

## Milestone 0 · Bootstrap (este repo)
Shell modular, docs, schemas y Workflow prototype.

## Milestone 1 · Core real
ProjectStore versionado + atomic writes, OperationLog/undo-redo, JobEngine persistente, AssetStore, Activity real.

## Milestone 2 · Canter Adapter
Import/interop con Canter 3.8.1, source map/transcript/fichas. No reescribir Canter todavía.

## Milestone 3 · Media Intelligence
Probe, proxy, waveform, filmstrip, transcript adapter, scene/face/geometry contracts.

## Milestone 4 · Dresser MVP
Manual B-roll placement + basic captions + frame-accurate editor + FFmpeg/VideoFlow projection.

## Milestone 5 · Batch automatic
20 clips → visual opportunities → stock/local photo/video → captions → final render → QA.

## Milestone 6 · Client system
Profiles, TXT import, AI roundtrip, style packs, fonts/tokens/glossary.

## Milestone 7 · Visual Lab
Search/generate/compare/import, asset provenance, providers, reference continuity.

## Milestone 8 · X-roll Visual Packs
TYPO, PHOTOS, OBJECTS, PHOTO_OBJECT, COMIC_INFO, later COMIC_CC.

## Milestone 9 · Workflow Studio
Recipe registry, typed nodes, array/router/conditions/HITL/retry.

## Milestone 10 · NLE Delivery
DaVinci package/MCP plan, FCPXML/EDL where appropriate, CapCut Kit.

## Milestone 11 · Browser-assisted
Adapters only for selected services; robust manual fallback.

## Milestone 12 · Advanced polish
Enhance/restoration, learned preferences, smoothing, advanced motion, agent runtime.
